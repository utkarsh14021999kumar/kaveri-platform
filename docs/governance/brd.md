# KAVERI - Business Requirements (BRD)
| ID | Requirement | Phase | Status |
|---|---|---|---|
| BR-01 | Infrastructure changes are reviewed, tested and approved before they reach any environment | 1 | Met |
| BR-02 | No static cloud credentials anywhere (keyless CI) | 1 | Met |
| BR-03 | Spend is visible per PR and alerted per month | 1 | Met (Infracost, budget) |
| BR-04 | Security findings are scanned, fixed, justified or risk-accepted - never silently ignored | 1 | Met |
| BR-05 | The application is deployed via GitOps with the same artefact promoted across environments | 2, 5 | Planned |
| BR-06 | Only signed, policy-compliant images run in clusters | 3 | Planned |
| BR-07 | Service health is measured against SLOs with actionable alerts | 4 | Planned |
| BR-08 | The platform can be rebuilt from code within the agreed RTO | 6 | Planned |
